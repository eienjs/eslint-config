You can set up `@eienjs/eslint-config` in seconds using the interactive CLI wizard or by installing the package manually.

## Interactive CLI Wizard (Recommended)

Run the CLI wizard in your project root to automatically install required dependencies, generate `eslint.config.js`, migrate any existing `.eslintignore`, and configure `.vscode/settings.json`:

::code-group

```bash [pnpm]
pnpm dlx @eienjs/eslint-config@latest
```

```bash [npx]
npx @eienjs/eslint-config@latest
```

```bash [bun]
bunx @eienjs/eslint-config@latest
```

::

See the [CLI Wizard](/packages/eslint-config/usage/cli-wizard) guide for non-interactive flags and framework templates.

## Manual Installation

::steps

### Install the packages

Install `@eienjs/eslint-config` and `eslint` as development dependencies:

::code-group

```bash [pnpm]
pnpm add -D @eienjs/eslint-config eslint
```

```bash [npm]
npm install -D @eienjs/eslint-config eslint
```

```bash [yarn]
yarn add -D @eienjs/eslint-config eslint
```

::

::tip
If you plan to enable optional integrations such as `adonisjs`, `nuxt`, `astro`, `formatters`, or `erasableSyntaxOnly`, see [Frameworks](/packages/eslint-config/usage/frameworks) for their respective optional peer dependencies.
::

### Create the configuration file

Create `eslint.config.js` (or `eslint.config.mjs` if your `package.json` does not have `"type": "module"`) in your project root:

```js [eslint.config.js]
import eienjs from '@eienjs/eslint-config';

export default eienjs();
```

### Add lint scripts to `package.json`

Add scripts to check and auto-fix files across your repository:

```json [package.json]
{
  "scripts": {
    "lint": "eslint . --fix",
    "lint:check": "eslint ."
  }
}
```

### Verify the setup

Run the lint check command to verify everything works:

```bash
pnpm run lint:check
```

::
